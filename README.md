# RealTimeTranslator

Windows 向けのリアルタイム翻訳デスクトップアプリです。指定したプロセス（ゲーム / 動画プレーヤー / 配信視聴クライアント等）の音声を翻訳字幕として表示できます。ボイス通訳では、自分のマイク音声を翻訳し、Wave Link 3 経由でゲームのボイスチャットへ送れます。字幕翻訳とボイス通訳は同時に使用できます。

> ⚠️ **データ送信について**: 本アプリは BYOK（Bring Your Own Key）モデルです。字幕翻訳・ボイス通訳の音声は OpenAI API へ送信され、OpenAI アカウントで料金が発生します。完全なローカル処理ではありません。

> 🔄 **自動更新がうまくいかない場合**
>
> 本アプリは Velopack による自動更新に対応していますが、ネットワーク環境やセキュリティソフトの影響で自動更新に失敗することがあります。その場合は、最新の Setup.exe を手動でダウンロードして上書きインストールしてください（設定・API キーはそのまま引き継がれます）。
>
> 👉 <https://rtt.kagayoi.com/RealTimeTranslator-win-x64-Setup.exe>

## ボイス通訳（Wave Link 3）

Wave Link 3 の利用には Windows 11 が必要です。字幕翻訳だけを利用する場合は Wave Link の導入は不要です。

1. [Elgato 公式ダウンロード](https://www.elgato.com/jp/ja/s/downloads)で **Wave Link 3** を選び、本体と **Audio Driver** を導入します。「ボイス通訳」タブで対象機器が見つからない場合は、画面内の「Wave Link 3 の初回設定」からダウンロードと[公式の説明](https://www.elgato.com/jp/ja/explorer/products/wave/wave-link-3-0-software-overview/)を開けます。権限の確認や再起動を求められた場合は、インストーラーの案内に従ってください。Wave Link 3 は本アプリに同梱していません。
2. Wave Link を起動し、翻訳音声専用の仮想入力チャンネル（例: **Aux 1**）を用意します。ゲームへ送る **Chat Mix** にはそのチャンネルだけを含め、物理マイク・ゲーム音・ほかの音声を外します。原音の二重送信やゲーム音の回り込みを避けるため、送話用ミックスを確認してください。ボイス通訳の利用中は Wave Link を起動したままにします。
3. 「API設定」タブで OpenAI API キーを設定します。ボイス通訳の翻訳音声は OpenAI を使用し、字幕側の接続・翻訳先言語とは独立しています。
4. 「ボイス通訳」タブで「機器一覧を更新」（初回設定内では「インストール後に再確認」）を押し、入力マイク、送信先の **Wave Link の翻訳専用再生チャンネル**、相手へ送る言語を選択します。手順2で用意したチャンネルと一致させてください。
5. ゲームのマイク入力には **Chat Mix (Elgato Virtual Audio)** を指定します。ゲームや Windows 全体の再生先は普段のヘッドホン等のままにしてください。
6. 「翻訳音声を送信」を選んで開始します。「原音を送信」では翻訳せずに送り、「ミュート」では無音になります。原音・ミュートでは翻訳 API に接続しません。

音声は **このアプリ → Wave Link の翻訳専用チャンネル → Chat Mix → ゲーム** の順に流れます。Windows やゲームの既定のマイク・再生先は自動変更しません。旧方式で保存した送信先 ID は自動変換しないため、Wave Link のチャンネルを明示的に選び直してください。機器の導入・一覧更新で字幕や API キーなどの設定は消去されません。字幕翻訳は対象プロセスからの別経路で、ボイス通訳と同時に使用できます。

「押している間だけ送信」が有効な場合は、既定の **F8** を押している間のマイク音声を取り込みます。停止中に発話キーのボタンを押し、登録したいキー（例: **Ctrl + Shift + V**）を実際に押して離すと変更できます。通常のキー1つに Ctrl・Shift・Alt・Win を組み合わせられ、Esc または別の操作への移動で登録をキャンセルできます。以前の単独キー設定も引き継ぎます。キーを離した後も、すでに取り込んだ発話の訳音声は最後まで送ります。ゲーム側は音声検出・常時送信に設定してください。同じ発話キーでゲームの PTT も閉じると、遅れて出る翻訳音声が切れます。「押している間だけ送信」を無効にすると、通訳モード中はマイク音声を継続して API に送ります。

「訳音声の試聴」でヘッドホンやスピーカーを明示的に選び、「翻訳音声を送信」で通訳を開始してから「訳音声を試聴」を押すと、ゲームへ送る訳音声を自分でも同時に聞けます。Wave Link のミックス設定を切り替える必要はありません。試聴先にはゲーム送信に使う Wave Link 以外の再生機器を選びます。スピーカーからマイクへの回り込みを避けるため、ヘッドホンを推奨します。試聴を停止してもゲームへの送信と字幕翻訳は継続し、発話キーを離した後の訳音声の末尾も試聴できます。試聴は起動時・通訳開始時にはオフです。

「音量と訳文」では、マイク入力と送信・試聴の出力をそれぞれ **−24～+24 dB** のスライダーで調整できます。既定は0 dBで、各「0 dB」ボタンで戻せます。メーターはゲイン適用後のレベルを表示し、赤い音割れ表示が点灯する場合はゲインを下げてください。入力ゲインは翻訳へ渡すマイク音声に、出力ゲインはゲーム送信と試聴の両方に適用します。原音モードにも両ゲインが適用され、通訳中でも接続し直さず変更できます。字幕翻訳の入力ゲインとは独立しています。

停止・モード切替では送話と試聴の保留音声を消去します。通信・機器障害や処理遅延が発生した場合も停止し、原音へ自動切替しません。試聴側の機器障害や過負荷は試聴だけを停止します。復旧後は再度開始してください。設定・接続・開始停止は字幕翻訳から独立しているため、一方を停止しても他方は継続します。

## 最近の更新（v1.0.60）

- 「押している間だけ送信」のキーを、実際にキーの組み合わせを押して登録できるようになりました。
- 訳音声をヘッドホンなどでも同時に聞ける試聴と、入力・出力を別々に調整できる音量スライダー・レベル表示を追加。
- VADの閾値・冒頭保持・末尾保持を個別に選択できるようにし、保持時間の既定値を50ms・200msへ変更。
- 字幕確定・接続更新・ボイス通訳の停止処理を改善し、音声出力停止時の診断情報を追加。未使用依存の削減とマイク処理の配列再利用で軽量化。

以前 OpenAI 以外を利用していた場合は、「API設定」タブで OpenAI API キーを設定してください。旧プロバイダのキーは OpenAI では利用できません。

## 音声検出の設定

「音声処理」タブで、閾値・冒頭保持・末尾保持をそれぞれ別のドロップダウンから選べます。閾値が高いほど音声と判定する条件が厳しくなり、冒頭・末尾の保持時間で発話の切れを抑えます。一つを変更してもほかの項目は変わりません。

| 項目 | 既定値 | 主な選択肢 |
| --- | --- | --- |
| 発話判定の閾値 | 0.8 | 0.6 / 0.8 / 1.0 |
| 発話冒頭の保持 | 50 ms | 0 / 50 / 100 / 200 / 500 / 700 / 1000 / 1200 / 2000 ms |
| 発話末尾の保持 | 200 ms | 0 / 100 / 200 / 350 / 500 / 800 / 1000 / 2000 ms |

保持時間は音声処理の単位に合わせて適用されるため、指定値と実際の時間には差があります。実装と既定値の根拠は [音声処理と VAD の設計](DESIGN.md#音声処理と-vad) を参照してください。

旧プリセット設定は初回に冒頭・末尾を新しい既定値へ移行し、閾値は保持します。旧カスタム設定と移行後の個別設定は保持し、既存の選択肢にない保存値も一覧に追加します。

## 機能

- **プロセス単位の音声キャプチャ**: 対象プロセスの音声のみを取得します。
- **ストリーミング翻訳**: 翻訳 API に音声をストリーミング送信し、翻訳テキストを逐次受け取って表示します。
- **半透明オーバーレイ字幕**: 透過・最前面・クリック透過対応のウィンドウに字幕を表示します。フォント・色・表示時間・行数を設定で調整可能。
- **日本語フォント同梱**: 字幕に最適な日本語フォント 5 種類 (IBM Plex Sans JP / Noto Sans JP / LINE Seed JP / Zen Maru Gothic / M PLUS Rounded 1c) を同梱しており、OS にフォントが入っていなくても綺麗な字幕表示が可能です。
- **背景色 12 種類**: 字幕の見やすさをシーンに合わせて選べる多色背景。枠色は背景の輝度から自動派生して常に視認性を保ちます。
- **字幕翻訳のコスト見える化**: 音声検出で無音区間の送信を抑制して API の課金を削減します。字幕セッションの経過時間 / 推定コスト (USD) / 節約秒数をリアルタイム表示します。ボイス通訳の利用分はこの表示に含みません。
- **翻訳ログ**: 確定字幕を ADV ゲーム風の会話ログ画面で閲覧できます。保持期間を 7 / 30 / 90 / 180 / 365 日 / 無制限から選択可能。
- **自動アップデート**: 起動時に自動で新版を確認し、ダイアログから更新できます。

## インストール

1. **Setup.exe をダウンロード**
   - <https://rtt.kagayoi.com/RealTimeTranslator-win-x64-Setup.exe>

2. **インストーラを実行**
   - ダウンロードした `RealTimeTranslator-win-x64-Setup.exe` をダブルクリック
   - インストール完了後、スタートメニューに「RealTimeTranslator」が追加されます

3. **OpenAI API キーを準備**
   - OpenAI のアカウントと API キーを用意

4. **アプリを起動して OpenAI を設定**
   - サイドバーの **「API設定」タブ** で OpenAI API キーを入力
   - 「接続テスト」ボタンで疎通確認

5. **翻訳を開始**
   - **「メイン」タブ** で対象プロセス（ゲーム / 動画プレーヤー等）を選択
   - 出力言語を選択して「開始」ボタンを押下
   - 半透明オーバーレイに翻訳字幕が表示されます

## 同梱フォント

字幕用に最適化された日本語フォント 5 種類を OFL (SIL Open Font License) 1.1 ライセンスで同梱しています。設定画面の「フォント」ドロップダウンで切り替え可能です。

- **IBM Plex Sans JP** (既定): 視認性高め
- **Noto Sans JP**: 漢字字数最多
- **LINE Seed JP**: 親しみやすい角丸
- **Zen Maru Gothic**: 柔らかい丸ゴシック
- **M PLUS Rounded 1c**: 丸みのあるモダンサンセリフ

システムフォント（Yu Gothic UI / Meiryo UI / Segoe UI / MS Gothic）も引き続き選択できます。

## トラブルシュート

### 翻訳結果が表示されない時

1. プロセス選択が正しいか確認 (オーディオ再生中のプロセスのみ翻訳対象になる)
2. 「API設定」タブで OpenAI API キー、契約・課金状態を確認
3. ネットワーク接続を確認

### 対象アプリがプルダウンに出てこない時

「対象プロセス」の一覧には **現在オーディオを再生しているプロセスのみ** が表示されます。 対象アプリで何か音を出してから **「更新」ボタン** を押してみてください。 ゲーム起動直後でタイトル画面の BGM がまだ鳴っていない場合は、 BGM が鳴り始めてから更新する必要があります。

### 音声は再生されているのに字幕が来ない時

1. アプリ画面のステータスバーに **赤いエラーバナー** が出ていないか確認 (API キー認証失敗 / 課金エラー等)
2. **「音声処理」タブ** で VAD の閾値と保持時間を確認。小さな声を拾えない場合は閾値を0.6へ下げ、冒頭・語尾が切れる場合は該当する保持時間を長くします。
3. ゲーム本体の音量設定が小さい場合は **「メイン」タブの入力ゲイン** を +6dB 〜 +12dB 上げて再試行
4. それでもダメな場合は対象プロセスを終了→再起動 → 翻訳側も Stop→Start

### 歌や BGM の歌詞も翻訳されてしまう

FireRed VAD のストリーミング版は会話と歌声を声として扱うため、 **歌モノ BGM の歌詞も字幕として翻訳します** (ゲーム OP/ED や挿入歌も対象です)。 翻訳したくないシーンは Stop ボタンで一時停止してください。

### API キーを入れたのに「キー未設定」と表示される

「API設定」タブの OpenAI API キー欄に余分な空白 / 改行が混入していないか、OpenAI の契約・課金状態が有効か確認してください。

### 課金が想定より高い

1. **「音声処理」タブ** で VAD の閾値を上げ、不要な音声が送信されないか確認（高すぎると発話も検出されにくくなります）
2. 「連続無音時間で自動停止」を有効化 (席を離れた間の token 垂れ流し事故防止)
3. **バージョンタブ → ログフォルダ** の最新ログで「セッション統計」を確認 → 完結文 emit と partial emit の比率、 累積 audio token 数が見える

### 自動更新が動かない時

1. **バージョンタブの「更新の確認」ボタン** を押して手動チェック
2. それでも動かない場合は <https://rtt.kagayoi.com/RealTimeTranslator-win-x64-Setup.exe> から最新インストーラを手動でダウンロードしてインストール

### ログ・設定ファイルの場所

アプリ内では **バージョンタブの「ログフォルダを開く」/「設定フォルダを開く」ボタン** からエクスプローラで直接開けます。API キーは OS のセキュアな暗号化機構で保護されており、別ユーザー / 別 PC では復号できません。

[GitHub Issues](https://github.com/1llum1n4t1s/RealTimeTranslator/issues) に再現手順 + 環境情報 (Windows バージョン) と、必要に応じてログを添付してお願いします。ログには翻訳テキストの先頭 40 文字が含まれるため、機密情報は事前に除去してください。
