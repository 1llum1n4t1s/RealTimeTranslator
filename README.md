# RealTimeTranslator

Windows 向けのリアルタイム翻訳デスクトップアプリです。指定したプロセス（ゲーム / 動画プレーヤー / 配信視聴クライアント等）の音声を翻訳字幕として表示できます。ボイス通訳では、自分のマイク音声を翻訳し、VB-CABLE 経由でゲームのボイスチャットへ送れます。字幕翻訳とボイス通訳は同時に使用できます。

> ⚠️ **データ送信について**: 本アプリは BYOK（Bring Your Own Key）モデルです。字幕用の音声は選択した OpenAI / Google Gemini / Soniox / Speechmatics / Azure AI Speech の API へ、ボイス通訳の音声は OpenAI API へ送信され、各アカウントで料金が発生します。完全なローカル処理ではありません。

> 🔄 **自動更新がうまくいかない場合**
>
> 本アプリは Velopack による自動更新に対応していますが、ネットワーク環境やセキュリティソフトの影響で自動更新に失敗することがあります。その場合は、最新の Setup.exe を手動でダウンロードして上書きインストールしてください（設定・API キーはそのまま引き継がれます）。
>
> 👉 <https://rtt.kagayoi.com/RealTimeTranslator-win-x64-Setup.exe>

## ボイス通訳（VB-CABLE）

1. [VB-Audio 公式サイト](https://vb-audio.com/Cable/)から標準の **VB-CABLE** を取得し、展開したインストーラーを管理者として実行して Windows を再起動します。VB-CABLE は本アプリに同梱していません。
2. 「API設定」タブで OpenAI API キーを設定します。ボイス通訳の翻訳音声は OpenAI を使用し、字幕側のサービス・翻訳先言語とは独立しています。
3. 「ボイス通訳」タブで入力マイク、送信先の **CABLE Input (VB-Audio Virtual Cable)**、相手へ送る言語を選択します。機器が表示されない場合は「機器一覧を更新」を押してください。
4. ゲームのマイク入力には **CABLE Output (VB-Audio Virtual Cable)** を指定します。ゲームや Windows 全体の再生先は普段のヘッドホン等のままにしてください。
5. 「翻訳音声を送信」を選んで開始します。「原音を送信」では翻訳せずに送り、「ミュート」では無音になります。原音・ミュートでは翻訳 API に接続しません。

このアプリから VB-CABLE に送る側が **CABLE Input**、ゲームが受け取る側が **CABLE Output** です。Windows やゲームの既定のマイク・再生先は自動変更しません。送信先が一覧にない場合は、VB-CABLE を明示的に選び直してください。機器の導入・一覧更新で字幕や API キーなどの設定は消去されません。

「押して話す」が有効な場合は、既定の **F8** を押している間のマイク音声を取り込みます（F6〜F12 へ変更可能）。キーを離した後も、すでに取り込んだ発話の訳音声は最後まで送ります。ゲーム側は音声検出・常時送信に設定してください。同じ発話キーでゲームの PTT も閉じると、遅れて出る翻訳音声が切れます。「押して話す」を無効にすると、通訳モード中はマイク音声を継続して API に送ります。

停止・モード切替では保留音声を消去します。通信・機器障害や処理遅延が発生した場合も停止し、原音へ自動切替しません。復旧後は再度開始してください。設定・接続・開始停止は字幕翻訳から独立しているため、一方を停止しても他方は継続します。自分の訳音声のモニター再生には対応していません。

## 最近の更新（v1.0.58）

- VB-CABLE 経由で自分の声をゲームへ翻訳音声として送る「ボイス通訳」を追加。既存の字幕翻訳と同時に利用できます。
- ボイス通訳の開始・停止、原音・ミュートへの切り替え、押して話す操作を字幕翻訳から独立して管理。
- VAD の感度プリセットを 0.60 / 0.80 / 0.90 に調整。発話の冒頭・末尾の保持時間とカスタム設定は維持。
- 字幕通知とアプリ終了時の処理を安定化。
- 発話後の無音送信（既定 5 秒）と、次の発話の冒頭・末尾を保持する処理は維持。

| VAD プリセット | 閾値 | 冒頭保持 | 末尾保持 |
| --- | --- | --- | --- |
| ふつう | 0.80 | 1000 ms | 800 ms |
| 頭と尻尾を取りこぼさない | 0.60 | 1200 ms | 800 ms |
| ガッツリ節約 | 0.90 | 700 ms | 350 ms |

旧設定でもプリセットを選んでいる場合は値を同期し、カスタム設定は保持します。元の暦を特定できない旧ログは推測で日付を補正せず、曖昧な名前の期限削除を保留します。

## 機能

- **プロセス単位の音声キャプチャ**: 対象プロセスの音声のみを取得します。
- **ストリーミング翻訳**: 翻訳 API に音声をストリーミング送信し、翻訳テキストを逐次受け取って表示します。
- **翻訳プロバイダの選択**: OpenAI / Google Gemini / Soniox / Speechmatics / Azure AI Speech の 5 つの翻訳プロバイダを「API設定」タブで切り替えられます（既定は OpenAI、再起動不要で次の翻訳開始から反映）。
- **半透明オーバーレイ字幕**: 透過・最前面・クリック透過対応のウィンドウに字幕を表示します。フォント・色・表示時間・行数を設定で調整可能。
- **日本語フォント同梱**: 字幕に最適な日本語フォント 5 種類 (IBM Plex Sans JP / Noto Sans JP / LINE Seed JP / Zen Maru Gothic / M PLUS Rounded 1c) を同梱しており、OS にフォントが入っていなくても綺麗な字幕表示が可能です。
- **背景色 12 種類**: 字幕の見やすさをシーンに合わせて選べる多色背景。枠色は背景の輝度から自動派生して常に視認性を保ちます。
- **字幕翻訳のコスト見える化**: 音声検出で無音区間の送信を抑制して API の課金を削減します。字幕セッションの経過時間 / 推定コスト (USD) / 節約秒数をリアルタイム表示します。ボイス通訳の利用分はこの表示に含みません。
- **翻訳ログ**: 確定字幕を ADV ゲーム風の会話ログ画面で閲覧できます。保持期間を 7 / 30 / 90 / 180 / 365 日 / 無制限から選択可能。
- **自動アップデート**: 起動時に自動で新版を確認し、ダイアログから更新できます。

## インストール

1. **Setup.exe をダウンロード**
   - <https://rtt.kagayoi.com/RealTimeTranslator-win-x64-Setup.exe>

2. **インストーラを実行**
   - ダウンロードした `RealTimeTranslator-win-x64-Setup.exe` をダブルクリック
   - インストール完了後、スタートメニューに「RealTimeTranslator」が追加されます

3. **利用する翻訳プロバイダの API キーを準備**
   - OpenAI / Google Gemini / Soniox / Speechmatics / Azure AI Speech のいずれかでアカウントと API キーを用意
   - Speechmatics と Azure は認識する元言語、Azure は Speech リソースのリージョンも確認

4. **アプリを起動して翻訳プロバイダを設定**
   - サイドバーの **「API設定」タブ** でプロバイダを選び、表示された認証情報を入力
   - 「接続テスト」ボタンで疎通確認

5. **翻訳を開始**
   - **「メイン」タブ** で対象プロセス（ゲーム / 動画プレーヤー等）を選択
   - 出力言語を選択して「開始」ボタンを押下
   - 半透明オーバーレイに翻訳字幕が表示されます

## 同梱フォント

字幕用に最適化された日本語フォント 5 種類を OFL (SIL Open Font License) 1.1 ライセンスで同梱しています。設定画面の「フォント」ドロップダウンで切り替え可能です。

- **IBM Plex Sans JP** (既定): 視認性高め
- **Noto Sans JP**: 漢字字数最多
- **LINE Seed JP**: 親しみやすい角丸
- **Zen Maru Gothic**: 柔らかい丸ゴシック
- **M PLUS Rounded 1c**: 丸みのあるモダンサンセリフ

システムフォント（Yu Gothic UI / Meiryo UI / Segoe UI / MS Gothic）も引き続き選択できます。

## トラブルシュート

### 翻訳結果が表示されない時

1. プロセス選択が正しいか確認 (オーディオ再生中のプロセスのみ翻訳対象になる)
2. 「API設定」タブで選択中プロバイダの API キー、契約・課金状態を確認。Azure はリージョンも確認
3. ネットワーク接続を確認

### 対象アプリがプルダウンに出てこない時

「対象プロセス」の一覧には **現在オーディオを再生しているプロセスのみ** が表示されます。 対象アプリで何か音を出してから **「更新」ボタン** を押してみてください。 ゲーム起動直後でタイトル画面の BGM がまだ鳴っていない場合は、 BGM が鳴り始めてから更新する必要があります。

### 音声は再生されているのに字幕が来ない時

1. アプリ画面のステータスバーに **赤いエラーバナー** が出ていないか確認 (API キー認証失敗 / 課金エラー等)
2. **「音声処理」タブ** で VAD プリセットを確認。 BGM 多めのシーンでは「ふつう」推奨、 ささやき声を逃すなら「頭と尻尾を取りこぼさない」へ
3. ゲーム本体の音量設定が小さい場合は **「メイン」タブの入力ゲイン** を +6dB 〜 +12dB 上げて再試行
4. それでもダメな場合は対象プロセスを終了→再起動 → 翻訳側も Stop→Start

### 歌や BGM の歌詞も翻訳されてしまう

FireRed VAD のストリーミング版は会話と歌声を声として扱うため、 **歌モノ BGM の歌詞も字幕として翻訳します** (ゲーム OP/ED や挿入歌も対象です)。 翻訳したくないシーンは Stop ボタンで一時停止してください。

### API キーを入れたのに「キー未設定」と表示される

「API設定」タブで現在選択しているプロバイダのキー欄に余分な空白 / 改行が混入していないか確認してください。別プロバイダのキーだけを入力しても開始できません。Azure はリージョンも必要です。

### 課金が想定より高い

1. **「音声処理」タブの VAD プリセット** を「ガッツリ節約」に切り替え
2. 「連続無音時間で自動停止」を有効化 (席を離れた間の token 垂れ流し事故防止)
3. **バージョンタブ → ログフォルダ** の最新ログで「セッション統計」を確認 → 完結文 emit と partial emit の比率、 累積 audio token 数が見える

### 自動更新が動かない時

1. **バージョンタブの「更新の確認」ボタン** を押して手動チェック
2. それでも動かない場合は <https://rtt.kagayoi.com/RealTimeTranslator-win-x64-Setup.exe> から最新インストーラを手動でダウンロードしてインストール

### ログ・設定ファイルの場所

アプリ内では **バージョンタブの「ログフォルダを開く」/「設定フォルダを開く」ボタン** からエクスプローラで直接開けます。API キーは OS のセキュアな暗号化機構で保護されており、別ユーザー / 別 PC では復号できません。
